Small mods for crowded checkouts.

When several Claude sessions share one checkout, they start duplicate servers, commit each other's half-done files and lose track of long plans. These mods catch those moments inside Claude Code.

Mods are plugins of function hooks that run inside Claude Code. What are mods?

Install
/plugin marketplace add thieung/claude-mods
/plugin install ghost-proc-guard@thieung-mods
/plugin install worktree-guard@thieung-mods
/plugin install ak-cockpit@thieung-mods
/reload-plugins
Run inside Claude Code 2.1.287 or later. Install only the mods you need.

Which one do you need?

Start from what went wrong.

  • Claude runs pnpm dev again and your app now runs on :5173 and :5174.ghost-proc-guard
  • Servers from last week's sessions are still holding ports.ghost-proc-guard
  • git add -A swept another session's half-done files into your commit.worktree-guard
  • git stash or reset --hard would throw away work you did not write.worktree-guard
  • A command failed with EADDRINUSE and you do not know who holds the port.worktree-guard
  • You only notice the context is full when it compacts, and lose your place in the plan.ak-cockpit

The mods

None of them makes network calls. Each README lists the programs it runs, the files it reads and what it keeps.

ghost-proc-guard

One dev server per checkout. Refuses a launch whose ports are taken, before the tool moves to the next free port.

/plugin install ghost-proc-guard@thieung-mods
Open the ghost-proc-guard pageSource
  • Reads ports from script flags, then vite, astro and wrangler config, then the tool default.
  • Understands turbo, pnpm, nx, lerna and npm workspaces, and places each server in its git worktree.
  • /procs lists the servers Claude started, in this session and earlier ones, and stops a whole app with one press.

worktree-guard

For worktrees several sessions share. Keeps one session from committing or throwing away another session's work.

/plugin install worktree-guard@thieung-mods
Source
  • git add -A, add ., add -u and commit -a are checked for files that were dirty before the session began. If there are any, you choose whether the command runs.
  • git stash, checkout ., restore, reset --hard and clean are dry-run first, so you see which files they would touch.
  • After EADDRINUSE, a toast names the process and folder holding the port.

ak-cockpit

An AgentKit band above the prompt: how full the context is, and where you are in the active plan.

Needs the ak CLI on PATH and the ak:handoff skill.

/plugin install ak-cockpit@thieung-mods
Source
  • Shows context fill and how much the last turn added. At 75% (configurable) the reading turns red and a Handoff button runs /ak:handoff.
  • Follows the newest plan in plans/ and shows the current phase with its checked tasks.
  • Press the band to open a pane with every phase and the open checklist items.

A mod runs with the same access as Claude Code itself: files, processes, network. Read the source before installing.
